# Emmanuel Isitor — Portfolio

A responsive, single-page portfolio website based on Emmanuel Isitor's CV.
It highlights his cloud data engineering experience, selected achievements,
technical expertise, transition toward AWS cloud engineering, education,
certifications, and contact details. It also notes that he is studying AWS
cloud engineering and has passed the AWS Solutions Architect – Associate exam.

## View the website

Open `index.html` in a web browser. The site uses plain HTML and CSS and does
not require a build step, package installation, or JavaScript framework.

## Project files

- `index.html` — page content and semantic structure.
- `style.css` — layout, colors, typography, and responsive styles.

## Customization

Edit the content in `index.html` and the design tokens and styles in
`style.css`. Contact links and experience details are included in the page
content. Check these details against the latest CV before publishing.

## Publishing

The site is static and can be served by any static web host. Upload `index.html`
and `style.css` together, keeping them in the same directory.
